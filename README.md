# Masa25-usagi

N高で学びながら、AIを使ってローカルツールやWebアプリを作っています。
拠点は北陸です。
音声AI、日々の情報整理、エージェントとの作業連携に関心があります。

公開用のソース、設定例、テスト、現在の制約を整えたツールを公開しています。開発中の機能も含みます。

## 主なツール

| ツール | できること |
| --- | --- |
| [Agent Live](https://github.com/Masa25-usagi/agent-live) | 音声AI・画面共有・エージェント連携 |
| [Life IQ](https://github.com/Masa25-usagi/life-iq) | 日々の情報を整理し、日次・週次の文脈を作る |
| [Meeting Slides](https://github.com/Masa25-usagi/meeting-slides) | 会話や文字起こしからスライドを作り、PPTX・HTMLへ書き出す |
| [Slack Session Kit](https://github.com/Masa25-usagi/slack-session-kit) | SDK・CLI・MCPからSlack操作を扱う |
| [GPT Call Mixer](https://github.com/Masa25-usagi/gpt-call-mixer) | 通話アプリとChatGPTの間の音声をつなぐmacOSミキサー |

## 開発について

- CodexなどのAIツールを使って実装・検証を進めています。
- 実際の利用データや認証情報を含めず、設定例や架空データを使って共有しています。
- 外部サービスとの連携や実機での動作確認の範囲は、各リポジトリの説明を参照してください。

不具合報告や改善案は、それぞれのリポジトリのIssueで歓迎します。
